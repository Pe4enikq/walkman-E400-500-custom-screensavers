## How to Use

1. Copy **one** `.nwm` file into the `NWWM-SCR` folder on your Walkman (delete any previous custom `.nwm` first — only one custom screensaver works at a time).
2. Or upload `.nwm` files directly with [Apollo Manager](https://github.com/Pe4enikq/Apollo-Manager).
